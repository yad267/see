# Встроить «лицо + эмоция» в твой завод (нода Обложка)

Да. Не отдельный бот — **замена плохой генерации внутри завода**.

## Почему старая «Обложка» обычно бесит
Типичный завод делает так:
1. AI пишет abstract prompt («businessman shocked…»)
2. Midjourney / Flux / DALL·E рисует **чужое** лицо
3. Текст кривой или его нет
4. Нет связи с **хуком** длинного ролика

Тебе нужно наоборот:
**твоё лицо → эмоция из хука сценария → punchy текст**

## Что менять в заводе
В ворке **Обложка** оставь:
- вход (title / script / хук из предыдущих нод)
- отправку в Telegram

**Вырежи / отключи** всё, что сейчас рисует картинку «с нуля» (HTTP к image model без твоего фото, Midjourney, Ideogram без face-ref и т.п.).

**Вставь вместо этого** модуль:
`oblozhka-factory-module.json`

## Как подключить (5 минут)
1. Import в n8n: `oblozhka-factory-module.json`
2. В основном заводе (или в ворке Обложка) добавь ноду **Execute Workflow** → выбери этот модуль
3. Перед Execute Workflow (Set / Code) передай:

| Поле | Откуда |
|------|--------|
| `title` | заголовок длинного ролика |
| `hook` | хук / первые 2–3 абзаца сценария (лучше всего) |
| `chatId` | твой Telegram chat id (как в заводе уже есть) |
| `referencePhotoUrl` | **прямая ссылка** на твоё портретное фото (Google Drive public / imgbb / S3) |

Пример JSON на входе Execute Workflow:
```json
{
  "title": "Почему мозг саботирует цели",
  "hook": "Ты думаешь, что ленивый. На самом деле тебя держит дофамин от коротких видео...",
  "chatId": "123456789",
  "referencePhotoUrl": "https://.../my-face.jpg"
}
```

4. Credentials в модуле: OpenAI + Telegram (те же, что в заводе)
5. Active ON на модуле

## Что получишь
После шага сценария/заголовка завод сам:
1. вытащит эмоцию из хука
2. отредактирует **твоё** фото (выражение + свет)
3. кинет в Telegram картинку + строку `Текст: ...`

Текст на картинке пока можно добить в Canva за 30 сек (или скажи — добавим авто-overlay).

## Если лень Execute Workflow
Можно **скопировать ноды** из модуля прямо в ворк «Обложка» и соединить:
`хук из завода → Analyze Hook → Download Face → OpenAI Image Edit → Send Photo`

## Мини-чеклист качества
- Фото: портрет, лицо ≥40% кадра, нейтральное, хороший свет
- В `hook` кидай **не только title**, а кусок сценария с болью/конфликтом
- Если результат «пластилин» — смени `openAiImageModel` или дай более чистое фото

## Файлы
- `oblozhka-factory-module.json` — модуль для завода
- `thumbnail-factory-v2.json` — отдельный Telegram-бот (если хочешь вручную)
- `PROMPT.md` — старый промпт концепций (можно не трогать)
