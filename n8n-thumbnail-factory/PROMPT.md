# Master Prompt — YouTube Thumbnail Factory

Используется в ноде Generate Concepts (system prompt).

Стиль: яркие бизнес-превью (Hartmann / Ситников).

Ключевые правила:
- 3–6 слов на обложке
- 1 визуальный фокус
- high contrast / mobile readable
- 3 разных угла: эмоция / конфликт / результат
- image prompt на английском, без текста на картинке
