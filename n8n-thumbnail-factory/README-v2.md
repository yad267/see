# Thumbnail Factory v2 — твоё лицо + эмоция по хуку

Минимум ручной работы:
1. Один раз отправляешь боту **своё фото** (референс лица)
2. На каждый ролик/шорт пишешь **хук** (1–2 предложения)
3. Бот присылает **готовое превью 1280×720** + текст на обложке

## Команды в Telegram
- Отправь **фото** (лучше портрет, лицо крупно) с подписью: `фото`
- Или текст: `фото` после отправки фото
- На каждый ролик:
```text
превью: Главный обман мозга — почему ничего не радует
```
или коротко хук из шорта:
```text
превью: Ты думаешь что ленивый, но это дофамин
```

## Что делает AI
1. Берёт **хук** → вытаскивает эмоцию (шок / боль / уверенность / конфликт)
2. Пишет **текст на обложку** (3–6 слов)
3. Меняет **выражение лица** на твоём фото (через OpenAI Image Edit)
4. Накладывает **фон/свет** в стиле Hartmann/Sitnikov (ярко, контраст)
5. Добавляет **текст** (если включён Cloudinary — автоматом; иначе текст отдельной строкой для 1 клика в Canva)

## Настройка n8n
1. Import `thumbnail-factory-v2.json`
2. Credentials: **Telegram Bot** + **OpenAI**
3. Config:
   - `telegramChatId`
   - `openAiImageModel` = `gpt-image-1` (или актуальная image model в аккаунте)
   - `cloudinaryCloudName` / `cloudinaryApiKey` / `cloudinaryApiSecret` — **опционально** (авто-текст на картинке)
4. Active ON

## Если Cloudinary не настроен
Бот пришлёт:
- картинку с твоим лицом и эмоцией
- строку **Текст на обложку:** `...`
Ты только вставляешь текст в свой Canva-шаблон (30 сек).

## Качество
- Референс-фото: нейтральное, хороший свет, лицо ≥40% кадра
- Хук: чем конкретнее, тем точнее эмоция
- Для шортов можно копировать первую фразу сценария
