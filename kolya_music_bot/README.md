# KolyaMusic — только n8n

Личный музыкальный архив в закрытой форум-группе Telegram.  
**Стек: n8n 24/7.** Не Python, не Mac.

Группа: `22:22 Music Search` (private + Topics).  
Бот: `KolyaMusic`.  
Не связан с заводом шортов / RentKolyaBot.

## Импорт (ты делаешь в n8n)

1. Открой `https://n8n.yad26ai.uk`
2. **Import from File** →  
   `n8n/KolyaMusic — Music Bot.json`
3. **Credentials → Telegram** → токен от BotFather для KolyaMusic  
   (имя например `KolyaMusic Bot`)
4. Во всех нодах Telegram / HTTP Request выбери этот credential  
   (после импорта часто слетает — пройди и привяжи)
5. **Active ON**
6. В группе (бот админ + **Управление темами**) напиши: `/setup`
7. Кинь тестовый трек (hip-hop в имени)

## Команды

| Команда | Что делает |
|---------|------------|
| `/setup` | Создаёт топики-жанры, помнит id |
| `/start` | Справка |
| `/genres` | Список папок |
| `/find hiphop` / название / год | Поиск по индексу → кнопки в папку |
| `переложить в hiphop` | Reply на трек — ручной перенос |

## Поток

```
трек в группу → классификация → топик
неуверен / руки → Inbox + кнопки
/find → нашёл → кнопкой в папку
```

Бот живёт на n8n. Терминал на Mac не нужен.
