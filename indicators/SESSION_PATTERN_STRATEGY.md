# EURUSD Session Pattern Strategy (M15)

Стратегия вокруг азиатского диапазона + паттернов подтверждения.
Таймфрейм: **M15**. Сессия по умолчанию: **00:00–08:00 UTC**.

## База

1. Пока идёт сессия — только наблюдение, сделок нет.
2. После конца сессии на графике остаются **High** (зелёный) и **Low** (красный).
3. Торгуем только реакции на эти уровни + паттерн.

## Паттерны на графике

| Метка | Что это | Идея входа |
|---|---|---|
| **BREAK ↑ / ↓** | Close за пределами range | В сторону пробоя |
| **FAKE ↑ / ↓** | Пробой был, но цена вернулась внутрь | Против пробоя (откуп/продажа обратно) |
| **RETEST ↑ / ↓** | После пробоя ретест уровня и отбой | В сторону пробоя |
| **PIN ↑ / ↓** | Пин-бар / отвержение у границы range | В сторону от тени |
| **ENGULF ↑ / ↓** | Поглощение у границы range | В сторону поглощения |

## Правила входа (кратко)

### A) Чистый пробой (BREAK)
- Close за уровнем.
- Стоп: за противоположную сторону микро-структуры / за середину range.
- Не усреднять.

### B) Ложный пробой (FAKE)
- Сначала был BREAK, затем close снова внутри range за N баров.
- Вход против пробоя.
- Стоп: за экстремум выноса (фитиль фейка).

### C) Ретест (RETEST)
- После BREAK цена возвращается к уровню и даёт отбой (пин / поглощение / close от уровня).
- Вход в сторону исходного пробоя.
- Стоп: за уровень + буфер.

### D) PIN / ENGULF у границы
- Без обязательного BREAK: реакция прямо от high/low сессии.
- Работает как контртренд к краю коробки (осторожнее).

## Риск

- 0.5–1% на сделку.
- 1 идея = 1 вход.
- Если через ~20 баров M15 цена обратно в коробке против позиции — идея слабая, выход.

- Сколько BREAK / FAKE / RETEST
- Winrate по типам сигналов после lookforward
