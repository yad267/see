# Session Confluence Strategy

Одна стратегия из двух смежных слоёв. Сигнал только когда они **подтверждают** друг друга.

## Слой 1 — структура (Азия range)
- **BREAK** — close за high/low сессии
- **FAKE** — пробой и возврат внутрь
- **RETEST** — пробой → возврат к уровню → отбой

## Слой 2 — свечи / паттерны
- **PIN** — длинная тень от уровня
- **ENGULF** — поглощение
- **FLAG** — сжатие после импульса + продолжение
- **IMPULSE** — сильная закрывающая свеча

## Как считается вход (SETUP)
Очки:
- FAKE или RETEST = **2**
- BREAK = **1**
- каждая подтверждающая свеча в ту же сторону = **+1**

**SETUP** рисуется только если сумма **≥ 2** (настройка) **и** есть свечное подтверждение в окне N баров.

Пример:
- голый BREAK без свечи → **нет входа** (только слабая метка, если включить)
- BREAK + PIN/ENGULF → **↑/↓ SETUP BREAK + PIN**
- FAKE + противоположная свеча → **SETUP FAKE** (торговля против ложного пробоя)

## Зачем
Меньше сделок, выше качество: в таблице сравнивай  
`RAW WR` vs `SETUP WR`.  
Если SETUP winrate выше — фильтр работает.

## Таймфрейм
EURUSD **M15**, сессия `0000-0800 UTC`.
