# Как поставить Gold MTF 3X в TradingView

## Что ставить
1. Сначала индикатор: `gold_mtf_3x_indicator.pine` — только метки SETUP  
2. Потом бот: `gold_mtf_3x_bot.pine` — сделки в Тестере стратегий  

Не ставь оба сразу, если не хочешь кашу на графике.

## Шаги
1. Открой **XAUUSD**  
2. Таймфрейм графика: **5 минут**  
3. Pine Editor → вставь код → **Добавить на график**  
4. Для бота открой внизу **Тестер стратегий**

## Что смотреть
- Фон графика зелёный = на 4H ищем только BUY  
- Красный = только SELL  
- Серый/нет фона = флэт, не торгуем  
- Жёлтый **SETUP / BOT** = вход по правилам  
- Зелёная линия = 1H support, красная = 1H resistance  

## Важно
Это симуляция TradingView, не автоордера брокера.  
Сначала смотри winrate в тестере 1–3 месяца, потом решай про реальные лоты.  
Копитрейд чужой «3X» не нужен — это твоя проверяемая версия тех же идей.
